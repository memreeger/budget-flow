# BudgetFlow

BudgetFlow, gelir ve giderleri kaydetmek ve bütçe durumunu takip etmek için geliştirilmiş basit bir web uygulamasıdır.

## Özellikler

- Gelir ve gider ekleme
- İşlemleri düzenleme ve silme
- İşlem arama ve filtreleme
- Toplam gelir, gider ve bakiye hesaplama
- Verileri tarayıcıda saklama
- Mobil cihazlara uyumlu tasarım

## Kullanılan Teknolojiler

- React
- Vite
- Tailwind CSS
- LocalStorage

## Kurulum

```bash
npm install
npm run dev
```

Ardından terminalde gösterilen yerel adresi tarayıcıda açabilirsin.

## Üretim Derlemesi

```bash
npm run build
```
